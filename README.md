# Musafir Café Website

A luxury café and roastery website inspired by the Openhouse Café aesthetic, featuring dark & light theme modes, aesthetic culinary photography, interactive table reservations, and full online ordering.

## Features
- **Design Aesthetic**: Openhouse luxury layout with Cormorant Infant serif, Josefin Sans typography, and brass accents.
- **Theme Switcher**: Instant Dark & Light mode toggle with saved preferences.
- **Aesthetic Visuals**: Curated photography of artisanal coffees, Himalayan mojitos, and gourmet grilled sourdough sandwiches.
- **Table Reservation**: Complete booking system with date picker, party size, and meal slots.
- **Full Menu & Ordering**: 169+ categorized menu items, dietary filters (veg/non-veg), and live cart drawer.
- **Interactive Experience**: Musafir Passport stamps, Postcard Memory Wall, and assistant chatbot.

## Running Locally
Simply open `index.html` in any modern web browser.
